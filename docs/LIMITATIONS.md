# 研究局限与不能宣称的内容

## 数据和选择
1. 训练只有44栋受损、8栋毁坏；验证只有3栋受损、没有毁坏。
2. 验证总交叉熵和按一般错误选择alpha容易受完整类主导，无法验证毁坏类模型选择是否合适。
3. 原配置中的样本目标/上限没有全部由准备实现保证，最终数据超过早期测试规模目标。公开实际清单与差异，不把配置目标当作实测结果。
4. 建筑与裁剪属于相关影像片；2410栋测试不等于2410个独立灾害事件。事件仅2个，泛化证据有限。
5. 文件哈希匹配可以验证交接一致性，不能证明整个实验无其他人工操作或独立证明先后顺序。

## 方法和结果
- 使用通用ImageNet主干，无专门SAR预训练或空间结构建模。
- 灾前光学单模态不能直接观察灾后损毁，可能依赖区域、建筑外观或灾害分布关联。
- 融合未超过光学macro-F1；三个模型macro-F1均低于训练多数类恒预测基线，但恒预测漏掉所有损毁。
- 融合损毁漏判102/222，误报亦很多，不适合实战部署或安全认证。
- 组合排序一般错误捕获增加，而损毁漏判捕获未体现优于随机。这两项目标不能混用。

## 人工复核边界
已有标签理想纠错假设选中的错误都被正确改正。没有真人耗时、判读正确率、疲劳、不一致性、现场核验等实验。交接无human_review.json，也没有测试失败案例影像；只提供现有逐样本数字案例和可运行查看器。

## 验证边界
发布端没有原始裁剪和全部NPZ，因此不能独立复算GPU特征、训练或完成影像查看器真实数据的端到端重跑。发布端完成指标、排名和哈希核对及轻量程序测试，范围见AUDIT.md。

## 下一步研究方向（尚未实施）
改善训练/验证损毁覆盖；采用适合SAR的归一化和主干；在验证阶段以损毁漏判捕获为排序目标；使用更多独立事件与片区级不确定性估计；进行有独立参考标准的真实人工复核。未来方向不是本仓库已取得的成绩。
