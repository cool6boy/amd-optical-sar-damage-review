# 任务流程与产物导航

本项目把“准备数据、计算、评价、解释”分开，保留每步的输入与输出。

| 阶段 | 输入与操作 | 设备 | 核心产物 | 检查点 |
|---|---|---|---|---|
| 1. 选定问题 | 已知建筑bbox，灾前光学与灾后SAR | CPU | 实验计划、固定配置 | 不宣称建筑检测或结构安全鉴定 |
| 2. 数据准备 | 固定revision、按需ZIP成员读取、配对和QC | CPU | manifest、selected_tiles、data_qc | 事件隔离、来源/裁剪重复、影像尺寸及地理参考 |
| 3. 标签隔离 | train/val用于拟合与选择，test由程序封存 | CPU | manifest中test label=null | 不按测试类别选择样本 |
| 4. 冻结特征 | ResNet18 ImageNet1K V1，各模态分别前向 | AMD GPU | NPZ缓存、features_complete | 内容/权重/预处理指纹兼容后才复用 |
| 5. 小头拟合 | 单模态512维、拼接1024维、3个seed | 源码实现为CPU | heads.pt、history | 均值/标准差与类权重只从train计算 |
| 6. 策略锁定 | val交叉熵、alpha候选 | CPU | policy.lock.json | 验证缺类警告保留，不把test当val |
| 7. 预测与评价 | 先预测，最终评价才读取test标签 | CPU | predictions、per_building、final_evaluation | 锁定模型/策略，校验关联哈希 |
| 8. 复核模拟 | 固定融合预测，同K比较3种排序 | CPU | 一般错误/剩余错误/损毁漏判对照 | 标为理想标签纠错模拟 |
| 9. 结果交付 | 从原结果派生图表、审核公开内容 | CPU | README、SVG图、文档、Release | 不发布原始影像/全部缓存/凭据 |
| 10. 真人复核 | 通过viewer观察影像并保留无法判断 | CPU + 操作者 | human_review.json | 本次交接未包含真人记录，不能声称已开展 |

## 一次特征计算，复用多个比较

三组轻量分类器与三种排序共享冻结特征。多个seed只是小头，不是重复训练多个ResNet18。改变标签选择/文档不要求重新计算兼容图像特征；改变输入、主干权重或实际预处理则不能无条件复用。

## 模型输出与人工判断

模型给出3类概率、argmax类别、熵及模态分歧排序。查看器中的“无法判断”是人工选择，不是已训练的第四类。图像质量不充分的样本可在QC阶段排除/保留原因；不能把未纳入模型的样本当作模型识别失败来凑案例。

## 本次交付阶段没有重跑训练

可视化、辅助二分类、训练多数类基线与跨事件描述性统计从既有结果计算，属于发布整理；保持原始预测、指标与模型文件不变。
